# Personal Finance Tracker PWA

നിങ്ങൾ ആവശ്യപ്പെട്ട എല്ലാ പ്രധാന ഫീച്ചറുകളും ഉൾപ്പെടുത്തി തയാറാക്കിയ Progressive Web App (PWA) സോഴ്സ് കോഡ് ഫയലുകൾ ഇതിലുണ്ട്.

### ഫയലുകൾ:
1. `index.html` - ആപ്പിന്റെ പ്രധാന UI, 50-30-20 ബജറ്റിംഗ്, തൽസമയ കണക്കുകൾ, CSV എക്സ്പോർട്ട് എന്നിവ അടങ്ങിയ ഫയൽ.
2. `manifest.json` - ഫോണിൽ/ഡെസ്ക്ടോപ്പിൽ App ആയി ഇൻസ്റ്റാൾ ചെയ്യാൻ സഹായിക്കുന്ന ക്രമീകരണങ്ങൾ.
3. `sw.js` - ഓഫ്‌ലൈൻ ആയി ആപ്പ് പ്രവർത്തിക്കാൻ സഹായിക്കുന്ന സർവീസ് വർക്കർ.

### എങ്ങനെ ഉപയോഗിക്കാം?
1. ഈ Zip ഫയൽ എക്സ്ട്രാക്റ്റ് (Extract) ചെയ്യുക.
2. Netlify, Vercel, അല്ലെങ്കിൽ GitHub Pages പോലുള്ള സൗജന്യ വെബ് ഹോസ്റ്റിംഗ് പ്ലാറ്റ്‌ഫോമുകളിലേക്ക് ഇത് അപ്‌ലോഡ് ചെയ്യുക (ഹോസ്റ്റ് ചെയ്യുക).
3. നിങ്ങളുടെ ഫോൺ ബ്രൗസറിൽ ഈ ലിങ്ക് തുറന്ന് "Add to Home Screen" നൽകിയാൽ ഇതൊരു standalone ആപ്പായി പ്രവർത്തിക്കും!
